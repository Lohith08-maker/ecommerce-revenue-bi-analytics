# Power BI Dashboard Blueprint

## Executive KPI row
Revenue | Orders | Average Order Value | Identified Customers | Units Sold

## Recommended visuals
1. Monthly Revenue Trend — line chart by month.
2. Revenue by Country — horizontal bar chart sorted descending.
3. Top Products by Revenue — bar chart using Description and Revenue.
4. Customer Performance — customer-level revenue and orders for identified CustomerID values.
5. Cancellation Analysis — cancellation value and trend.

## Filters
Date, Country, Product / Description

## Interpretation Notes
Use the completed-sales rules consistently. Do not fabricate missing CustomerID values. December 2011 is partial and should be labelled clearly. Treat observed patterns as descriptive, not causal.
